colleges.json — world institution directory (bundled, static).
Source: Wikidata (https://www.wikidata.org), structured data under CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/).
Built 2026-09-21: universities/colleges (P31 instance of university/college
subclasses) with coordinates (P625) and country (P17); city from P131.
Records: 33347. Fields: name, country, city, lat, lng.
No live lookups: this file ships with the app; the picker labels it a
"Bundled institution directory". Coordinates are as published on Wikidata.

Supplement 2026-09-21: ~4,300 additional U.S. institutions (including community
colleges) merged from the U.S. Department of Education College Scorecard API
(https://collegescorecard.ed.gov/data/), a U.S. federal public-domain dataset.
A handful of well-known campus aliases (e.g. Dallas College - North Lake
Campus, Irving TX) were added manually with real coordinates.

schools_us.json — USA K-12 institution directory (bundled, static).
Built 2026-09-24 by data/build_schools_us.py (re-runnable). Official NCES
data only; no coordinates were invented.

Public schools: NCES Common Core of Data (CCD), Public Elementary/Secondary
School Universe, school year 2024-25
(https://nces.ed.gov/ccd/Data/zip/ccd_sch_029_2425_w_1a_073025.zip).
CCD rows scanned: 102,178.
Statuses INCLUDED (operating schools): Open, New, Reopened, Future, Added,
"Changed Boundary/Agency". Statuses EXCLUDED: Closed (1,068), Inactive (501).
All school levels included (elementary, middle, high, pre-K, secondary,
other, ungraded, adult education). All 50 states + DC + outlying areas
(PR, GU, VI, MP, AS) present.
Public coordinates: NCES EDGE 2023-24 public-school geocodes
(https://nces.ed.gov/programs/edge/data/EDGE_GEOCODE_PUBLICSCH_2324.zip),
joined by NCES school ID. Schools with no 2023-24 EDGE match (e.g. schools
new in 2024-25) keep null lat/lng — never estimated or invented.

Private schools: NCES Private School Universe Survey (PSS) 2023-24
public-use file (https://nces.ed.gov/surveys/pss/zip/pss2324_pu_csv.zip),
the latest PSS release (2025-26 data not yet published). The public-use file
contains responding eligible schools only; it ships its own latitude/longitude
(LATITUDE24/LONGITUDE24). PSS rows scanned: 22,510.

Exact duplicates on (normalized name, city, state) collapsed once: 499.
Final counts: 100,514 public + 22,106 private = 122,620 school records.
Geocoded: 121,597. Null coordinates (searchable, not mappable): 1,023.
City format: "City, ST" (e.g. "Austin, TX") to disambiguate same-name schools.
Fields: name, country, city, lat, lng. Records sorted by name.
Transparency: 197 school names also appear in colleges.json (separate files;
K-12 directory is not merged into or deduped against the college directory).
Merged with colleges.json at runtime in js/store.js (loadColleges); cache key
bumped to orbit_colleges_v3.
